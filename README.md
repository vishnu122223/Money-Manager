# 💰 Money Manager

A simple and intuitive personal finance management application designed to help users track income, manage expenses, and monitor their financial activities.

## ✨ Features

- 📊 Track income and expenses
- 💸 Manage daily transactions
- 📈 View financial summaries
- 🗂️ Organize and review transactions
- 🎨 Clean and responsive user interface

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite
- **Backend:** Node.js
- **Styling:** CSS
- **Development Tools:** Git, GitHub, npm

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/vishnu122223/Money-Manager.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Money-Manager
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the backend:

   ```bash
   node server/index.js
   ```

5. Start the frontend using the appropriate frontend directory and its development command.
